# xusers-app

XMARKET users console — standalone React + Vite PWA sharing the XMARKET Supabase DB.

## Features
- Access-code gate (`VITE_USERS_ACCESS_CODE`)
- Full user profiles list with all fields
- Create / edit / delete users
- Quick status toggle (active / frozen / banned)
- Search across email, username, name, phone
- Installable PWA (same icon as XMARKET)
